# مواءمة AI — النسخة المطوّرة

هذه نسخة مطوّرة من مشروع **مواءمة AI** مبنية لاستخدام **جميع الزوار مجانًا**، مع وظيفة أساسية هي:

- **مساعد عام عربي** يشبه تجربة المحادثة الحديثة.
- **ربط برامج مواءمة** في صفحات مستقلة داخل نفس الموقع.
- **حصص يومية** لضبط الاستخدام المجاني العام.

## ما الجديد في هذه النسخة؟

### 1) بنية أفضل للموقع
تم تقسيم الواجهة إلى:
- `index.html` الصفحة الرئيسية
- `chat.html` صفحة المحادثة
- `programs.html` صفحة عرض البرامج
- `program.html` صفحة تفصيلية لكل برنامج

### 2) هوية بصرية مبنية على مراجعك
تم اعتماد:
- الهوية البنفسجية الأساسية لمواءمة
- ألوان فرعية مستقاة من البرامج المختلفة
- أسلوب بطاقات احترافي ومتجاوب
- دعم عربي RTL كامل

### 3) نظام حصص مناسب للزوار المجانيين
القيم الافتراضية الحالية:
- **12 رسالة يوميًا** لكل زائر
- **3 عمليات بحث يوميًا** لكل زائر

يمكن تعديلها من ملف `wrangler.toml`:
```toml
DAILY_LIMIT = "12"
SEARCH_DAILY_LIMIT = "3"
```

### 4) إعداد البرامج من ملف واحد
كل بيانات البرامج موجودة في:
- `public/data/programs.js`

وبذلك تستطيعين تعديل:
- اسم البرنامج
- لونه
- الشرح المختصر
- النتائج المتوقعة
- عناصر التعلم
- مميزات الفئة الأساسية والاحترافية

## طريقة التشغيل والنشر

## أولًا: تجهيز Cloudflare
1. أنشئي حسابًا في Cloudflare.
2. أنشئي KV namespace باسم مناسب، مثل `LIMITS`.
3. ضعي المعرّف داخل `wrangler.toml` بفك تعليق قسم `kv_namespaces`.
4. أضيفي سر Tavily إذا أردتِ البحث المباشر:
```bash
npx wrangler secret put TAVILY_API_KEY
```

## ثانيًا: تشغيل محلي
```bash
npm install
npx wrangler dev
```

## ثالثًا: النشر
```bash
npm run deploy
```

## رابعًا: الرفع إلى GitHub
- ارفعي جميع ملفات المشروع إلى مستودع GitHub.
- اربطي Cloudflare بالمستودع إذا أردتِ نشرًا تلقائيًا.

## ملاحظات مهمة
- GitHub وحده مناسب لحفظ الكود، لكن **الذكاء الاصطناعي والمفاتيح والحصص** تحتاج خادمًا مثل Cloudflare Workers.
- نظام الحصص الحالي يعتمد على **عنوان IP** وهو مناسب كبداية، لكنه ليس نظام اشتراكات أو تسجيل دخول.
- عند التوسع مستقبلًا يفضّل إضافة:
  - تسجيل دخول
  - قاعدة بيانات للمحادثات
  - لوحة تحكم للبرامج
  - نموذج تواصل أو تسجيل اهتمام

## التطوير المقترح لاحقًا
- إضافة لوحة تحكم لإدارة البرامج بدون تعديل الكود
- حفظ المحادثات في قاعدة بيانات
- ربط نماذج تسجيل لكل برنامج
- إضافة صفحة “من نحن” و”تواصل معنا”
- إضافة نطاق مخصص وهوية كاملة

## ملاحظات تخص هذه النسخة
هذه النسخة مطوّرة بناءً على اختيارك:
- **نوع المستخدمين:** جميع الزوار مجانًا
- **الوظيفة الأساسية:** مساعد عام مع ربط برامج مواءمة

لذلك فالواجهة الحالية تعطي أولوية إلى:
1. سهولة التجربة لأول مرة
2. تعريف المستخدم ببرامج مواءمة
3. منع الاستهلاك المفرط للحصة المجانية
4. قابلية التعديل السريع لاحقًا

## تسمية محرك البحث والمحادثة
- الاسم الظاهر للمحرك: **مواءمة**.
- اسم المنصة التقنية: **مواءمة AI**.
- يعرض المحرك نمطين: محادثة بالذكاء الاصطناعي، وبحث إنترنت اختياري مع مصادر عند إعداد Tavily.
- لا يمكن ادعاء أنه نسخة مطابقة لـ ChatGPT أو أن البحث متصل دون تفعيل مزودي الخدمة.


## اللمسات النهائية — التحديث الحالي

- صفحات إضافية: `about.html` للتعريف، و`faq.html` للأسئلة الشائعة، و`contact.html` لإعداد ونسخ رسالة تواصل، و`privacy.html` لمسودة سياسة الخصوصية وشروط الاستخدام.
- استخدام صورة شعار مواءمة الأصلية المرفقة في ترويسة الموقع، مع استمرار تلوين بطاقات البرامج وفق هويتها.
- رابط لتجاوز القائمة إلى المحتوى (إتاحة)، وتحسينات للعناصر القابلة للتركيز، واستجابة أفضل للأجهزة الصغيرة.
- خيارات محادثة: الوضع الداكن، نسخ نص المحادثة، وتصديرها كملف TXT إلى الجهاز.
- ملف `manifest.webmanifest` لإظهار اسم المنصة عند تثبيتها كتطبيق ويب، **لا يوفر وضع عدم الاتصال بالذكاء الاصطناعي**.
- تنبيه الخصوصية: لا يوجد إرسال فعلي من صفحة التواصل حاليًا. زر نسخ الرسالة ينسخ النص فقط؛ يجب تكوين قناة التواصل الرسمية قبل الإطلاق.

## قائمة التفعيل قبل الإطلاق

1. أنشئي مساحة KV وأضيفي معرفها إلى `wrangler.toml` ثم نفذي `npm install` و`npx wrangler deploy`.
2. اختبري ربط Workers AI في حساب Cloudflare. النموذج الافتراضي مثال ويمكن استبداله بنموذج مدعوم.
3. إذا أردتِ البحث المباشر أضيفي `TAVILY_API_KEY` كسرّ في Cloudflare. لا ترفعي المفاتيح إلى GitHub.
4. اختبري الحصص من الأجهزة المختلفة. **KV والتعرف عبر IP يوفران حصة تقريبية لا حدًا صارمًا في الطلبات المتزامنة**؛ للإطلاق الواسع استخدمي Durable Objects أو تسجيل دخول/حلًا أقوى لمكافحة الإساءة والإنفاق.
5. تحققي من نصوص ووصف وأسعار ومواعيد البرامج وروابط التسجيل وحالة العلامات التجارية مع مالك المشروع قبل نشرها للجمهور.
6. عيّني بريد تواصل رسميًا وسياسة خصوصية قانونية مكتملة قبل الإطلاق العام.
7. GitHub يستضيف الكود. تشغيل المحرك نفسه يحتاج Cloudflare أو استضافة خادم مكافئة؛ رفع الملفات لا يجعل الذكاء الاصطناعي يعمل تلقائيًا.

## التحقق المنفذ

تم فحص وجود صفحات HTML جميعها وصحة بناء ملفات JavaScript نحويًا. **لم يُنفَّذ نشر على الإنترنت، ولم يُختبر اتصال نموذج AI أو Tavily فعليًا**؛ لأن حسابات ومفاتيح المستخدم غير متصلة ببيئة التطوير الحالية.
